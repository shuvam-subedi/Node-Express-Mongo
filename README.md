Tutorial for MongoDB + Node.js+ Express.js

Dependencies:
    1. Nodemon<br>
        Automates server restart (causes vulnerabilities so removed)<br>
    
    2. dotenv<br>
        Loads key-value pairs from .env files<br>

    3. Express<br>
        Framework for Node.js to simply backend development
    
    4. Mongoose<br>
        To simplify APi working with JS documents.
